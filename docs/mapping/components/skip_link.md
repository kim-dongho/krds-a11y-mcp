| KWCAG       | 필수 입력 필드           | 검증 규칙                                                                                                                                                                                         |

| kwcag:6.4.1 | skipTargetId (`a[href]`) | 페이지에 실존하는 id여야 하며 **본문(주 콘텐츠) 시작 요소**를 가리켜야 함. 킷 샘플 기본값 `#breadcrumb`를 그대로 쓰기 금지(아래 ? 참조). 대상 요소가 초점을 받을 수 있어야 함(`tabindex="-1"` 등) |

| kwcag:6.4.1 | 킷 샘플의 href가 `#breadcrumb` — 텍스트("본문 바로가기")와 실제 도착지(브레드크럼)가 불일치. **[PoC 실측 2026-09-11]** krds.go.kr에서 `axe:skip-link` **위반 확정** — `<a href="#breadcrumb-home">본문 바로가기</a>`인데 해당 id가 페이지에 **존재하지 않는다**(수동 확인). 킷 데모에서도 같은 규칙이 검출됐으나 그쪽은 조각만 렌더한 탓이 커서 킷 결함의 근거로는 약하다. 확정된 것은 **킷 샘플의 기본 href가 본문이 아닌 브레드크럼을 가리켜, 그대로 복사하면 위험하다**는 점 — ② skipTargetId 강제로 대응한다. 실사용 재현 증거: `../evidence/skip-link-*.jpg` (Tab으로 링크가 나타나지만 Enter를 눌러도 초점이 이동하지 않음) |

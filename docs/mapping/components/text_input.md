# text_input × KWCAG 2.2 매핑

> 기준: 킷 v1.1.0(d6bb184) · KWCAG 2.2(KS X OT0003) · axe-core v4.13.0 · 여기 없는 항목은 전부 N/A. 공통 규칙·부록은 ../component-kwcag-map.md 참조

## krds:text_input (텍스트 입력 필드)

- 검토 파일: `html/code/text_input.html`, `text_input_icon.html`, `text_input_size.html`, `text_input_state.html` (4파일 전수)
- 변형: 기본(readonly/disabled 포함), icon(비밀번호 보기·내용 삭제 버튼), size, state(error/success/information)

### ① 자동 충족

| KWCAG               | 근거                                                                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| kwcag:6.1.1         | 네이티브 `<input type="text                                                                                                                            | password">`+ 부속 버튼도 네이티브`<button>` |
| kwcag:5.1.1 (#icon) | 부속 아이콘 버튼에 킷이 sr-only 텍스트를 직접 제공 — `<span class="sr-only">입력한 비밀번호 보기</span>`, `내용 삭제` 등 (킷 텍스트를 수정 없이 쓸 때) |
| kwcag:6.5.3         | `<label for>`↔`<input id>` 연결 구조 — 가시 레이블 텍스트가 곧 접근 가능한 이름                                                                        |
| kwcag:6.5.2         | 입력 자체는 네이티브 컨트롤 — 브라우저 기본 활성 동작(업 이벤트 기반)                                                                                  |

### ② 조건부 — 필수 입력

| KWCAG                | 필수 입력 필드                              | 검증 규칙                                                                                                                                                                                                                                        |
| -------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| kwcag:7.3.2          | labelText                                   | 비어있음 금지 (axe:label). placeholder만으로 레이블 대체 금지 — 킷 데모의 "레이블" 자리 텍스트 교체 필수                                                                                                                                         |
| kwcag:7.3.2          | inputId                                     | `label[for]`와 `input[id]` 일치 필수, 비어있음 금지                                                                                                                                                                                              |
| kwcag:8.1.1          | inputId                                     | 페이지 내 유일 (킷 데모 id `consult_name` 등 복붙 시 중복 위험)                                                                                                                                                                                  |
| kwcag:7.3.1 (#state) | errorMessage + aria 연결                    | `is-error` + `p.form-hint-invalid` 사용 시 메시지 비어있음 금지·정정 방법 포함. **킷 마크업에는 `aria-describedby`/`aria-invalid` 연결이 없음** — 사용자가 `input[aria-describedby]`→힌트 id, `aria-invalid="true"`를 추가해야 보조기술에 전달됨 |
| kwcag:7.3.4          | autocomplete (개인정보·반복 입력 필드일 때) | 유효한 autocomplete 토큰 (axe:autocomplete-valid) — 킷 마크업에 autocomplete 속성 없음                                                                                                                                                           |

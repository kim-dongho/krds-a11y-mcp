## krds:pagination (페이지네이션)

- 검토 파일: `html/code/pagination.html` · `resources/js/component/ui-script.js` (pagination 전용 스크립트 없음 — 정적 마크업)

### ① 자동 충족

| KWCAG       | 근거                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| kwcag:6.1.1 | 페이지 링크가 네이티브 `<a href>`; 비활성 "이전"은 `<span>`(비상호작용 요소)이라 키보드 초점이 가지 않음 — 죽은 컨트롤에 초점이 가는 문제가 구조적으로 없음 |
| kwcag:6.4.3 | "이전"/"다음" 텍스트 링크 + 현재 페이지에 `span.sr-only`("현재페이지 ") 부가 — 링크 텍스트만으로 용도 식별 가능                                             |

### ② 조건부 — 필수 입력

| KWCAG       | 필수 입력 필드                                   | 검증 규칙                                                                                              |
| ----------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| kwcag:6.4.3 | pageHref (각 `a.page-link`·`a.page-navi`의 href) | 실제 목적지 필수(샘플 `#` 잔존 금지); 현재 페이지 항목에는 `active` 클래스 + 현재 위치 알림 하나 — `aria-current="page"`(템플릿 교정본·생성 마크업 방식) 또는 킷 원본의 sr-only "현재페이지". 둘을 함께 두면 두 번 읽힌다 |

## 확인 방법 상세

- **선형구조·지시문**: Playwright로 11종 프리뷰의 `document.body.innerText`를 추출해 시각 배치와 대조. 지시문은 추출 텍스트에서 "빨간·파란·오른쪽·왼쪽·둥근·큰 버튼" 등 패턴 검색
- **단축키·포인터·동작**: 템플릿 html 전수 + 킷 `resources/js/component/ui-script.js`에서 keydown/mousedown/devicemotion/change 핸들러를 검색해 키 조건까지 확인
- **대비·구분**: `pnpm report:templates`의 대비 실측(글자·배경색 계산) + 1280px 스크린샷 11장 판독 (apply-form 단계 표시, login-id 라벨, apply-detail 우측 고정 목차, apply-list 필터 박스, login-select 카드, main-portal 구획 — 보류 사유별 대표 확인)

## 조건부 3건의 처리

셋 다 "템플릿이 위반했다"가 아니라 "완성된 사이트에서만 판정 가능하다"는 뜻이다.
소비자에게 전달되도록 다음에 반영돼 있다:

1. 7.2.2 → withSiteChrome 사용 안내 (get_page_scaffold 응답)
2. 7.3.1 → 수동 확인 매뉴얼의 절차 + 킷 form-hint-invalid 패턴 권장
3. 7.3.3 → 수동 확인 매뉴얼의 절차 (인지 테스트 대체 수단)

리포트(report:templates)의 수동 체크리스트가 매 실행마다 이 3건을 사람 확인 항목으로 계속 노출한다 — 템플릿 검증이 끝났다고 항목이 사라지지 않는다.
